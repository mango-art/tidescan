# TideScan：A股模拟交易训练

Java 21 + Spring Boot 单机 Web 程序。日线与股本快照位于项目的 `data/market.db`，已缓存的分钟行情位于 `cache/minute`；账户数据也写入项目的 `data` 目录。工作目录须为项目根目录。分钟行情在查看或回放时按需缓存。

## 启动

双击 `start-tidescan.bat`，保持窗口运行，浏览器访问 http://127.0.0.1:8080/。首次同步需要较长时间；同步未完成期间选股页面会提示未覆盖的股票数量。关闭程序后可再次启动继续同步。

从源码构建（需要 Java 21 和 Maven）：

```powershell
mvn "-Dmaven.repo.local=F:/tidescan/maven-repository" test package
```

运行时从项目根目录的 `data/secrets.properties` 读取 `mairui.daily-licence` 和 `mairui.minute-licence`：

```properties
mairui.daily-licence=你的日线许可证
mairui.minute-licence=你的分钟许可证
```

该文件不在版本管理中，换机器时需自行创建；缺失时程序仍可启动，但同步行情和选股会提示凭证未配置。许可证只由后端读取。程序监听本机 8080 端口，不对局域网开放。

## 使用

1. 选择已同步的历史交易日或点击随机日期，开始游戏。
2. 根据需要修改参数，使用选股日完整日 K 运行条件选股。执行选股或下一次选股时会弹出进度窗，显示已检查股票数量与命中数；完成前及发现数据缺失时不要把结果当作完整股票池。
3. 选择股票，按可用资金比例提交手动买入，按当日收盘价模拟成交。该价格是事后已知的收盘价，无法证明盘前按该价真实成交。
4. 逐分钟、连续播放或倍速推进，同一模拟时钟用于所有股票；连续播放只在当前回放日的分时内进行，播到 15:00 自动停止，不会跨入下一交易日。播放中若当前股票已清仓，时钟直接跳到当日收盘并停止播放；未清仓则继续播放到收盘。持仓可在后续交易日手动卖出，卖出成交后，分时图和当日日 K 都显示 S 标记。
5. 全部卖出后，可随时按“停止回放”，再按“执行下一次选股”。系统把当前回放交易日推进至收盘，按页面现有参数运行新一轮选股，资金与交易记录连续保留；持仓或待成交订单未清空时不能推进。
6. 结束游戏时持仓按当时可见价格作结算估值，记录标为结算，不当作真实成交。
7. 查看交易记录、已实现盈亏、胜率及当前持仓估值。密码 `123456` 用于重置账户；重置会清空账户、持仓和交易记录。

## 数据和模拟边界

- 选股使用当天完整日 K 与当时已经公告且已生效的流通股本；日线为不复权数据。选股日之后的行情仍受回放时钟限制。
- 当前沪深及北交所股票列表由麦瑞当前列表提供，历史退市股票、历史名称和历史股票池覆盖尚未核实，存在幸存者偏差。历史股本缺失和分钟行情缺失会显示数量，不能把缺失视为不满足条件。
- 日线和分钟成交量目前按接口返回“手”换算为股。已使用平安银行 2025-01-02 对比日线与分钟量：两个接口数值相等，分钟成交额相符；其他市场单位仍应核实。
- 买入以当日收盘价模拟，卖出使用下一分钟开盘价；默认佣金 0.03%（最低 5 元）、过户费 0.001%、卖出印花税 0.05%；卖出时价格锁定或无成交量的分钟拒单。收盘买入不判断涨停排队和实际成交能力；该撮合不含盘口排队、历史涨跌停规则细节、滑点、除权除息与持仓股数调整，不能等同真实交易。
- 一分钟接口首次取回后缓存在项目的 `cache` 目录，使用 5 GiB 上限和最近访问清理。沪深、北交所相关授权及数据范围由实际凭证决定。
- 最大回撤、完整盈亏分析、公式文本编辑、逐笔成交和精确历史复权尚未实现。对于跨除权除息的持仓，账户金额和收益可能偏差较大。

## 测试

`mvn test` 覆盖选股关键阈值、分钟数据时间边界、SQLite 持久化、订单在下一分钟成交、T+1、未来分钟数据隐藏和密码重置。`tests/browser-smoke.cjs` 为本机 Playwright 页面检查脚本。
